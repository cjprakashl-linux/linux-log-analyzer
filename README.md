# Linux Log Analyzer

A Bash-based log analysis tool for Linux administrators.

## Features

* Counts Error Messages
* Counts Warning Messages
* Counts Critical Events
* Displays Recent Errors
* Helps with Basic Troubleshooting

## Supported Platforms

* CentOS
* RHEL
* Rocky Linux
* AlmaLinux
* Ubuntu

## Usage

```bash
chmod +x log_analyzer.sh
./log_analyzer.sh
```

## Example Use Cases

* Service Failures
* Application Errors
* Boot Problems
* Troubleshooting Activities
